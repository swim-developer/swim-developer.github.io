Deploy a Provider Validator

The Provider Validator simulates an ANSP consumer. It subscribes to your provider, receives events, and validates that the provider's AMQP implementation, message format, subscription handling, and heartbeat conform to SPEC-170. The companion video demonstrates this deployment on an OpenShift environment.

Video walkthrough: Deploy a Provider Validator

Steps

  1. Deploy the Provider Validator using the provided Custom Resource
  2. Configure the validator to subscribe to your provider's AMQP endpoint
  3. Publish test events through the provider
  4. Review the validator's compliance report
  5. Address any non-conformance issues flagged by the validator
